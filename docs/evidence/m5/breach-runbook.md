# Breach notification

A personal-data breach is reportable within the statutory window. This runbook is the M5 record of that duty. It does not set an hour count the specification does not give.

1. Confirm the clinic, the data involved, and when the breach was noticed.
2. Preserve the audit log. Do not update or delete it.
3. Tell the clinic owner and report the breach within the statutory window.
4. Record the notice in the audit log.
